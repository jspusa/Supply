# Prototype verdict

## Question

Which Apple-inspired, no-sidebar workspace structure best keeps Supply short while keeping Taiwan, Vietnam, and the single Subcontract vendor unmistakably separate?

## Decision

Use Variant A, **Focused workspace**, as the production direction. It keeps a centered sticky five-workspace navigation, compact summary metrics, one visible work area, a bounded order table, and a clearly segmented Taiwan/Vietnam/Subcontract control without recreating a side rail.

Bring two details from Variant C into the production design: an inline explanation for the highest-priority Velocity Risk and one clear next action inside each workspace.

Do not use Variant B's left work queue because it recreates the asymmetry the user wants removed. Do not use Variant C's oversized hero because it reduces working density and makes fewer order rows visible.

At a 1280 by 720 viewport, Variant A had no page-level horizontal overflow, stacked package and box lines at the same horizontal position, and a document height of about 825 pixels versus about 3,150 pixels for the empty live page baseline.
